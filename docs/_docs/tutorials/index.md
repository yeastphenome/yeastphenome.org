# External Resources

## Notebooks

 - [Google AI Blog: Applying Machine Learning to Yeast](https://ai.googleblog.com/2020/04/applying-machine-learning-toyeast.html?m=1): includes a [GitHub repository](https://github.com/google-research/google-research/tree/master/yeast_transcription_network) to reproduce the analysis.
 - [Searching for Coding Sequences in yeast genomes using BLAST and Python](https://github.com/fomightez/blast-binder) 
 - [Intermine with Binder](https://github.com/fomightez/guide_to_intermine-binder) and also [intermine-binder](https://github.com/fomightez/intermine-binder)
 - [Methods in Yeast Genetics](https://github.com/fomightez/methods_in_yeast_genetics) notebooks for doing calculations related to Methods in Yeast Genetics book.

## Libraries

 - [YeastMine Examples](https://github.com/fomightez/yeastmine): example scripts using [YeastMine](https://yeastmine.yeastgenome.org/yeastmine/begin.do) to collect Saccharomyces Genome Database data.

## Yeast Imaging

 - [Imaging tools for Yeast](https://github.com/fomightez/imaging_tools_for_yeast)
