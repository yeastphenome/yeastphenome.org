# A Model Organism

Yeast is a model organism because it can reproduce (a process called "budding" to produce
an almost identical offspring) in about 90 minutes [^budding]. This means that if a typical
yeast can go through 30 [^googleai] of these events before death, we can study the entire life (and aging)
cycle of an organism in 2700 minutes, or just under two days. Yeast also has ~6,275 genes, of which 23%
are homologous to humans [^genes]. This makes the organism a good model for studying aging in human, 
because we can age and perturb the yeast, and then test if discoveries are relevant to humans.

[^budding]: https://www.quora.com/How-long-do-yeast-cells-take-before-dividing
[^googleai]: https://ai.googleblog.com/2020/04/applying-machine-learning-toyeast.html?m=1
[^genes]: https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5525645/
