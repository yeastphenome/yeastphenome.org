Project

About

YeastPhenome.org is a collaborative project that builds and maintains the compendium of systematic loss-of-function phenotypes for budding yeast Saccharomyces cerevisiae.

As part of this project, we track, collect and annotate all published phenotypic screens that involve the yeast knock-out collection. We extract the data, standardize their format and structure and make them available for search, download and analysis. Our main goal is to enable ourselves and others to answer the following questions:

  • Has phenotype X ever been measured systematically for all knock-out mutants? How many times? In what conditions? Where were the results published? Where can I download the data?
  • Have any phenotypes related to X been tested? Do any phenotypes appear to be related to X by co-occurring in the same mutants?
  • What genes rank the highest/lowest for phenotype X? How does gene Y rank relative to all other genes? What other phenotypes have been reported for gene Y? Do any other genes share the same phenotypes?

Criteria for inclusion

In order to be included in the compendium, a study must meet all of the following criteria:

  • Measure a quantitative (continuous) or qualitative (binary, discrete, categorical) phenotype (or the lack thereof) for at least 1,000 knock-out mutants
  • Use any current or past version of the haploid (Mat-a or Mat-alpha), homozygous diploid or heterozygous diploid deletion collection (BY4741, BY4742 or BY4743)
  • Report data on all of the tested mutants or just the most extreme/significant hits
  • Be associated with a journal article indexed in Pubmed

We do not include:

  • Large-scale screens of other yeast libraries (e.g., the library of DAmP strains, ts mutants or the prototrophic variant of the knock-out library).
  • Studies that report an arbitrary subset of hits chosen based on biological interest.
  • Genetic interaction screens, i.e. screens where knock-out mutants are examined under a secondary perturbation that is genetic, not chemical or physical.

Data sources

Our primary source of data is the main text and/or the supplementary material of a publication as provided by the journal’s website. When appropriate, we also download data from personal websites that accompany publications.

After downloading the data, we evaluate their completeness relative to the experiment described in the publication and reach out to the authors whenever we see that additional data may be available. For example, if the publication describes the measurement of a quantitative phenotype but only reports a binary list of hits, we ask whether the authors would be able to share the original quantitative dataset. Similarly, we often enquire about the availability of a list of tested strains for each experiment (despite the fact that everyone used the same yeast knock-out library, the actual "tested universe" in each experiment varies by as much as 20%). These datasets, which are effectively unpublished versions of published data, are explicitly flagged in the YeastPhenome.org database to emphasize their special status. The scientists who answered our emails and shared data are acknowledged as data contributors.

Data handling

For all data, we minimize manual handling to maximize record keeping and reproducibility. The only two operations performed manually are 1) data download and 2) conversion from PDF to a computer-readable format (text or Excel files), whenever required.

All other data manipulations (QC, clean-up, reformatting, database upload etc.) are done in Python via Jupyter notebooks. All code is version controlled and stored in a Github repository (to be made public soon).

Data normalization

To facilitate both analysis and interpretation of diverse Yeast Phenome data, we implemented several conventions and normalizations. Phenotypes reported on qualitative (e.g., mild, intermediate, severe) or categorical (e.g., round, elongated, irregular) scales (2% of datasets) were converted into sets of discrete (1, 2, 3) or binary (0, 1) values. Quantitative and truncated quantitative phenotypes (i.e., those reported on a quantitative scale only for the set of mutants considered to be hits) were transformed so that the sign and magnitude of their values were consistent with how the phenotype and its corresponding experimental condition are defined in their respective controlled vocabularies (higher values correspond to higher expressions of the phenotype, and vice versa). Since different phenotypes followed dramatically different distributions but were consistently unimodal, we used the mode as a reference to normalize each dataset using a modified z-score transformation.

$$NPS_i = {P_i - P_{mode} \over \sqrt{\frac{1}{N} \sum_{i=1}^N (P_i - P_{mode})^2}}$$

Where:
NPSi = normalized phenotypic score for knock-out mutant i
Pi = raw phenotypic score for knock0out mutant i (as reported by the original publication)
Pmode = mode of the kernel density distribution of phenotypic values for all knock-out mutants in this screen
N = total number of knock-out mutants tested in this screen

As a result, all phenotypic values reported in Yeast Phenome can be universally interpreted as standardized deviations from the most typical mutant, which, assuming extreme phenotypes are rare, is also likely to represent wild-type. The transformed data, which we refer to as normalize phenotypic scores (NPS), are used throughout the website. The original data are available at the Github repository (to be made public soon).

Computing correlations

To compute robust gene-gene phenotypic similarities in a computationally efficient and parallelizable manner, we adopted the following strategy.

  1. Given a data matrix, where rows correspond to genes, columns correspond to phenotypic screens and the values are normalized phenotypic scores (NPS), we created 100 submatrices by subsetting 10% of the columns using random sampling with replacement.
  2. For each of the submatrices, we computed gene-gene cosine correlations using a parallelized implementation by deepgraph.
  3. For each gene pair, we combined the 100 sampled cosine correlations by computing the mean and standard deviation.

Data usage and citation policy

If you use data downloaded from YeastPhenome.org in a talk or a manuscript, please acknowledge the data source by citing the original publication from which the data is derived, as well as the YeastPhenome.org database. The database should be cited as follows:

The YeastPhenome.org Database, www.yeastphenome.org, accessed on XXXX-XX-XX.
